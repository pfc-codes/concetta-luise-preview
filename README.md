# Concetta Luise — website preview

This repository contains only the rendered review website. The editable project, CMS configuration, drafts and private handoff materials are maintained separately.

## Enable GitHub Pages

In Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**, then Save.

The intended website address is https://pfc-codes.github.io/concetta-luise-preview/. It becomes available after GitHub Pages deploys successfully.

This is a public review site with noindex metadata. Anyone can access or copy these website files; noindex is not access control.

Updates are generated from the private project and replace these rendered files. The weekly anagram advances in the browser without a weekly deployment.
